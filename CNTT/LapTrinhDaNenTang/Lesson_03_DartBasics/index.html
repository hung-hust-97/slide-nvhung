ĐẶC ĐIỂM NỔI BẬT CỦA DART

Statically Typed with Type Inference

Khai báo tường minh hoặc để Dart tự suy luận kiểu. `var x = 10` → Dart biết x là int. Không lỗi type runtime.

Null Safety

Dart 2.12+ null safety bắt buộc. Non-nullable by default. `String?` có thể null, `String` không bao giờ null. Trình biên dịch phát hiện lỗi null ngay lúc compile.

First-Class Functions

Function là object, có thể gán vào biến, truyền làm tham số. Higher-order functions dễ dàng.

Strong Equality

2 biến == so sánh giá trị, không phải reference. Không cần .equals() như Java. `int x = 5; print(x == 5); // true`

Async/Await Native

Future và Stream là first-class citizens. async/await syntax clean, dễ đọc. Event loop đơn giản.

✨ XU HƯỚNG HIỆN ĐẠI

Dart 3.0+ với Records, Patterns, Sealed classes, Class modifiers. Dart 3.5+ (2024) cải thiện performance và tooling. Dart trở thành top-15 ngôn ngữ lập trình thế giới (TIOBE).

NỀN TẢNG THỰC THI DART

Các nền tảng thực thi

DART VM — Native

Chạy trực tiếp trên máy. Dart SDK: dart run, dart compile exe. Server-side, CLI tools, Flutter engine embedding.

JAVASCRIPT (dart2js)

Compile Dart → JavaScript. dart compile js. Web apps chạy trên browser. React Native không hỗ trợ Dart.

WEB ASSEMBLY (WASM)

dart compile wasm. Flutter 3.22+ hỗ trợ WASM output. Performance gần bằng native, cross-browser compatible.

AOT — Ahead of Time

Compile trước khi chạy → Native ARM code. Flutter production builds dùng AOT. Fast startup, predictable performance.

JIT — Just in Time

Compile khi chạy. Development mode: Hot Reload dùng JIT. Fast edit-refresh cycle.

Compilation targets

Nền tảng Compile
Android (Flutter) AOT → ARM
iOS (Flutter) AOT → ARM64
Web (Dart) dart2js / WASM
Desktop AOT → Native
Server Dart VM / AOT

"Flutter dùng AOT cho production (performance) và JIT cho development (hot reload). Cả 2 worlds best."

CÚ PHÁP CƠ BẢN — IDENTIFIERS & BIẾN

Quy tắc Identifiers

Quy tắc đặt tên

Phải bắt đầu bằng chữ cái (a-z, A-Z) hoặc dấu gạch dưới `_`. Tiếp theo là chữ cái, chữ số, hoặc `_`.

Valid identifiers

name, userName, _privateVar, hello123, camelCase, snake_case

Private modifier

Tên bắt đầu bằng `_` là private trong library. VD: `_UserService` chỉ truy cập được trong cùng file.

Reserved keywords

if, else, for, while, class, import, null, true, false, void, var, const, final, return, async, await...

Everything is an Object

Mọi thứ lưu trong biến đều là Object (kể cả numbers và null). Tất cả objects kế thừa từ base class Object.

// Mọi thứ đều là Object
var number = 42;       // int là Object
var text = 'Hello';     // String là Object
var isValid = true;    // bool là Object
var nothing = null;    // null là Object
var pi = 3.14;         // double là Object

// Kiểm tra kiểu runtime
print(number is int);      // true
print(text is String);     // true
print(nothing == null);    // true

CONSTANT & FINAL — KHAI BÁO HẰNG SỐ

const vs final

// const — compile-time constant

// const expression

// Sai:

// Explicit type

Sự khác biệt const vs final

Tiêu chí const final
Thời điểm gán Compile time Runtime (1 lần)

Object Immutable deeply Immutable reference

OPERATORS — CONDITIONAL & ASSIGNMENT

Conditional Operators

// Ternary: condition ? expr1 : expr2
var status = age >= 18 ? 'Adult' : 'Minor';

// Null-aware: expr ?? default
var name = nullable ?? 'Guest';
var len = nullable?.length ?? 0;

// Cascade notation (..)
var paint = Paint()
  ..color = Colors.blue
  ..strokeWidth = 2.0
  ..style = PaintingStyle.stroke;

// Null cascade (?..
var paint2 = maybeNull
  ?..color = Colors.red
  ?..strokeWidth = 2.0;

Assignment Operators

// Basic assignment
var x = 10;

// Shortcut assignment
var y = 5;
y += 3;    // y = 8
y -= 2;    // y = 6
y *= 2;    // y = 12
y ~/= 3;  // y = 4
y %= 3;   // y = 1

// Compound assignment
x ??= 20; // x = x ?? 20
// Nếu x là null → gán 20
// Nếu x != null → giữ nguyên

Lưu ý

??= khác với ??: gán khi null, không thay thế giá trị. Dùng nhiều trong Flutter state management.

EXCEPTION HANDLING — TRY/CATCH/THROW

Exception handling

// try-catch-finally
try {
  var result = 10 ~/ 0;  // divide by zero
} on IntegerDivisionByZeroException {
  print('Cannot divide by zero');
} catch (e, stackTrace) {
  print('Error: \$e');
  print('Stack: \$stackTrace');
} finally {
  print('Always executes');
}

// Throw exception
void checkAge(int age) {
  if (age < 0) {
    throw ArgumentError('Age cannot be negative');
  }
}

// Custom exception
class CustomException implements Exception {
  final String message;
  CustomException(this.message);
  @override
  String toString() => message;
}

Assert

// Assert — debug only
assert(text != null, 'Text must not be null');
assert(index >= 0 && index < length);
assert(value > 0, 'Value must be positive');

// Flutter: assert chỉ chạy trong debug mode
// Production: assert bị bỏ qua

// Rethrow
try {
  // code có thể lỗi
} catch (e) {
  // Xử lý một phần
  rethrow;  // Ném lại cho caller xử lý tiếp
}

Best practice

Dùng try-catch cho expected errors (network, user input). Assert cho development-only checks. Throw cho programmer errors.

FUNCTIONS — KHAI BÁO VÀ SỬ DỤNG

Function cơ bản

// Cú pháp
return_type function_name(param_list) {
  // statements
  return value;
}

// Ví dụ
String sayHello(String name) {
  return 'Hello, \$name!';
}

// Không cần return type → void
void printSum(int a, int b) {
  print('Sum: \${a + b}');
}

// Function là first-class object
var sayHello = (String name) => 'Hello \$name';
Function(int) double = (int x) => x * 2;

// Higher-order function
void executeTwice(Function fn) {
  fn();
  fn();
}

Function types

// Typed function parameters
int calculate(int a, int b, int Function(int, int) op) {
  return op(a, b);
}

var result = calculate(5, 3, (a, b) => a + b);
print(result);  // 8

// Void function type
void Function(String) logger = (msg) {
  print('[LOG] \$msg');
};

// Nullable function
void Function(String)? optionalCallback;
optionalCallback?.call('message');

Closure

Function có thể capture variables từ enclosing scope. Closure trong Dart có thể truy cập biến bên ngoài ngay cả khi enclosing function đã return.

FUNCTION — OPTIONAL PARAMETERS & DEFAULT VALUES

Optional Positional Parameters []

// Optional positional [] — nhận null
double sum(var a, [double? b, double? c]) {
  var total = a;
  if (b != null) total += b;
  total += (c != null) ? c : 0;
  return total;
}

sum(1);       // 1.0
sum(1, 2);    // 3.0
sum(1, 2, 3); // 6.0

// Gọi với named parameters
sum(1, c: 3, b: 2); // 6.0

Optional Named Parameters {}

// Named parameters với {}
double sum({
  required double a,
  double b = 1,
  double c = 2,
}) {
  return a + b + c;
}

// Gọi với tên
sum(a: 10);              // 13
sum(a: 10, b: 5);         // 17
sum(a: 10, b: 5, c: 3);   // 18
sum(b: 5, a: 10, c: 3);  // 18 (tên nên thứ tự không quan trọng)

// Nullable named parameter
void greet(String name, {String? title}) {
  print('\$title \$name');
}
greet('Hung', title: 'Mr.');

Flutter convention

Flutter dùng named parameters làm chuẩn. `required` bắt buộc phải có. Đây là best practice trong Flutter community.

ARROW FUNCTIONS & ANONYMOUS FUNCTIONS

Arrow function (Shorthand)

// Arrow syntax: => expression
return_type function_name(params) => expr;

double sum(double a, double b) => a + b;
int square(int x) => x * x;
bool isEven(int x) => x % 2 == 0;
void greet(String name) => print('Hello \$name');

// Anonymous function
var multiply = (int a, int b) => a * b;
print(multiply(3, 4));  // 12

// Anonymous function với block
var calculate = (int a, int b) {
  var result = a + b;
  return result * 2;
};

Anonymous functions usage

// Anonymous function với forEach
var numbers = [1, 2, 3, 4, 5];
numbers.forEach((n) {
  print(n * 2);
});

// Arrow trong forEach
numbers.forEach((n) => print(n * 2));

// Anonymous function làm parameter
var doubled = numbers.map((n) => n * 2).toList();
var evens = numbers.where((n) => n.isEven).toList();
var total = numbers.reduce((a, b) => a + b);

// Callable class
class Adder {
  int call(int a, int b) => a + b;
}
var adder = Adder();
adder(3, 4);  // 7 — gọi như function

Callable class

Dart 3.0: implement `call` method → instance có thể gọi như function. Dùng nhiều trong state management.

GETTER / SETTER — TRUY CẬP THUỘC TÍNH

Getter & Setter

class Circle {
  double _radius = 0;

  // Getter
  double get radius => _radius;
  double get diameter => _radius * 2;
  double get area => 3.14159 * _radius * _radius;

  // Setter
  set radius(double value) {
    if (value < 0) {
      throw ArgumentError('Radius cannot be negative');
    }
    _radius = value;
  }

  // Read-only (chỉ getter)
  String get info => 'Circle(r=\$_radius)';
}

Sử dụng getter/setter

var circle = Circle();
circle.radius = 10;   // setter → validate
print(circle.area);  // getter → 314.159
print(circle.diameter); // getter

// Dart tự động tạo implicit getter/setter
// cho mọi instance field
class BankAccount {
  double _balance = 0;
  double get balance => _balance;
  set balance(double v) => _balance = v;
}

Khi nào dùng?

Getter: tính toán derived values. Setter: validate trước khi gán. KHÔNG dùng getter/setter khi chỉ get/set đơn giản.

Extension với generics

// Extension on generic type
extension ListExtension<T> on List<T> {
  T? get firstOrNull => isEmpty ? null : first;
  T? get lastOrNull => isEmpty ? null : last;

  List<T> sortedBy(Comparable Function(T) keyOf) {
    return [...this]..sort((a, b) =>
      keyOf(a).compareTo(keyOf(b)));
  }

  Map<K, List<T>> groupBy<K>(K Function(T) keyOf) {
    var map = <K, List<T>>{};
    for (var item in this) {
      (map[keyOf(item)] ??= []).add(item);
    }
    return map;
  }
}

ITERABLES — LAZY COLLECTIONS

Iterable methods

var nums = [1, 2, 3, 4, 5, 6];

// map — transform
nums.map((x) => x * 2);          // [2,4,6,8,10,12]

// where — filter
nums.where((x) => x.isEven);     // [2,4,6]

// reduce — accumulate
nums.reduce((a, b) => a + b);   // 21

// fold — reduce với initial value
nums.fold(0, (sum, x) => sum + x); // 21

// expand — flatten
[[1,2],[3,4]].expand((x)=>x);  // [1,2,3,4]

// takeWhile, skipWhile
nums.takeWhile((x) => x < 4);   // [1,2,3]

Lazy evaluation

// Iterable lazy — không execute ngay
var evens = nums
  .where((x) => x.isEven)  // lazy
  .map((x) => x * 10)      // lazy
  .take(2);                 // lazy

// toList — trigger evaluation
var result = evens.toList(); // [20, 40]

// Generate
Iterable.generate(5, (i) => i * i); // [0,1,4,9,16]

// Range
var range = [for (var i=0; i<5; i++) i]; // [0,1,2,3,4]

// Any, Every
nums.any((x) => x > 5);   // true
nums.every((x) => x > 0); // true

Lazy = hiệu suất

NULL SAFETY TRONG THỰC HÀNH

Null safety types

// Nullable: có thể null
String? nullable;  // null
nullable = null;  // OK
nullable = 'text'; // OK

// Non-nullable: không bao giờ null
String nonNull = 'text'; // OK
nonNull = null;  // LỖI!

// Null assertion !
String? opt;
String must = opt!; // OK nếu opt != null
                       // RUNTIME ERROR nếu opt == null

// Null-aware operators
var len = nullable?.length; // null nếu nullable == null
var val = nullable ?? 'default'; // 'default' nếu null
var len2 = nullable ?? nullable2?.length ?? 0;

Pattern matching null

// if-null assignment
String name = nullable ?? 'Unknown';

// Type promotion
void foo(String? s) {
  if (s != null) {
    print(s.length); // Dart biết s != null
  }
}

// Final với late
class User {
  final String name;
  late final int _age;  // gán sau

  User(this.name);

  void setAge(int age) {
    _age = age;
  }
}

// Null safety trong collections
List<String?> mixed = [1, null, 3]; // nullable elements
List<String?>? maybeList; // nullable list

Best practice

Tránh dùng ! khi có thể. Dùng ??, ?. ?.isEmpty, ?.isNotEmpty. Đặt non-nullable làm default.

CLOSURES & LEXICAL SCOPING

Closure

// Closure — function + captured variables
Function makeAdder(int addBy) {
  return (int x) => x + addBy;
}

var addBy2 = makeAdder(2);
var addBy10 = makeAdder(10);

print(addBy2(5));    // 7
print(addBy10(5));   // 15

// Captured variable mutable (với var)
Function counter() {
  var count = 0;
  return () => ++count;
}

var counter1 = counter();
var counter2 = counter();
print(counter1()); // 1
print(counter1()); // 2
print(counter2()); // 1

Lexical scoping

var x = 'global';

void main() {
  var x = 'local';
  print(x);     // 'local' — shadowing

  void inner() {
    var x = 'inner';
    print(x); // 'inner'
    print(this.x); // 'global'
  }

  inner();
  print(x); // 'local'
}

// IIFE — Immediately Invoked Function
(() {
  var temp = setup();
  use(temp);
})();

Flutter use case

Closure dùng nhiều trong callback, event handlers. Builder pattern, Provider, BLoC đều dựa trên closures.

EQUATABLE & VALUE EQUALITY

Value equality trong Dart

// Dart dùng == so sánh giá trị, không reference
var a = [1, 2, 3];
var b = [1, 2, 3];
print(a == b); // true — cùng content

var obj1 = User('Hung', 28);
var obj2 = User('Hung', 28);
print(obj1 == obj2); // false mặc định
// Dart không auto-generate == cho class tự tạo

// Giải pháp: override ==
class User {
  final String name;
  final int age;

  @override
  bool operator ==(Object other) {
    if (identical(this, other)) return true;
    return other is User && other.name == name
        && other.age == age;
  }

  @override
  int get hashCode => Object.hash(name, age);
}

Equatable package

// equatable — auto-generated ==
import 'package:equatable/equatable.dart';

class User extends Equatable {
  final String name;
  final int age;

  const User(this.name, this.age);

  @override
  List<Object?> get props => [name, age];
}

var u1 = User('Hung', 28);
var u2 = User('Hung', 28);
print(u1 == u2); // true — tự động
print(u1.hashCode == u2.hashCode); // true

Khi nào dùng Equatable?

BLoC pattern, state management, caching. Dùng khi 2 objects cùng props = same identity.

TYPE TESTING & CASTING

Type checking

// is — kiểm tra kiểu runtime
if (obj is String) { ... }
if (obj is! int) { ... }

// isAs — kiểm tra + cast
if (obj is String) {
  var str = obj as String; // an toàn
  print(str.length);
}

// Pattern matching (Dart 3.0)
switch (value) {
  case int i when i > 0:
    print('Positive int: \$i');
  case String s:
    print('String: \$s');
  default:
    print('Unknown type');
}

Type promotion

// Dart tự động promote non-nullable
void foo(String? s) {
  if (s != null) {
    print(s.length); // s is String
  }
}

// Local variable — promoted
String? name;
if (name != null) {
  print(name.length); // Dart biết name != null
}

// KHÔNG promote — instance field
class A {
  String? field;
  void test() {
    if (field != null) {
      print(field!.length); // cần !
    }
  }
}

// Cast với as
(var a, var b) = ('text', 42); // record

Lưu ý

Type promotion chỉ hoạt động với local variables. KHÔNG với fields. Dùng `!` hoặc patterns cho fields.
