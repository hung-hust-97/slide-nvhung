NAVIGATION LÀ GÌ?

Navigation là quá trình chuyển đổi giữa các màn hình (pages/screens) trong một ứng dụng.

Navigator trong Flutter

Flutter sử dụng Navigator để quản lý navigation — hoạt động như một stack.

push

Mở trang mới

Page mới được đẩy lên trên stack

pop

Quay lại

Page hiện tại được bật ra khỏi stack

Navigator Methods phổ biến

push()

Mở trang mới, thêm vào stack

pop()

Quay lại trang trước

pushReplacement()

Thay thế trang hiện tại bằng trang mới

pushNamed()

Mở trang theo tên đã đăng ký

ROUTING LÀ GÌ?

Định nghĩa

Routing là quá trình ánh xạ route name (string) đến một Widget cụ thể.

Giúp quản lý rõ ràng các màn hình, đặc biệt trong ứng dụng có nhiều trang.

Lợi ích

  • Quản lý navigation tập trung
  • Hỗ trợ deep linking
  • Đặt tên rõ ràng cho mỗi route
  • Dễ dàng navigate từ bất kỳ đâu

MaterialPageRoute

Loại route mặc định trong Flutter, cung cấp Material Design transition.

MaterialPageRoute(
  builder: (context) => MyPage(),
);

✨ XU HƯỚNG HIỆN ĐẠI

GoRouter (Google's official routing package) đang thay thế Navigator 1.0 truyền thống — declarative routing, deep linking tự động, web URL support.

ANONYMOUS ROUTES

Định nghĩa

Anonymous route là route không được khai báo trước trong MaterialApp.routes, mà được tạo theo yêu cầu.

  • Không có route name (như /login, /home)
  • Không dùng với pushNamed()
  • Phù hợp cho app nhỏ, ít màn hình
  • Không cần cấu hình tập trung

Khi nào dùng?

App đơn giản, 2-3 màn hình, hoặc khi centralized routing không cần thiết.

Ví dụ

// Mở trang mới
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (context) => SecondPage(),
  ),
);

Không cần khai báo route trong MaterialApp. SecondPage được tạo trực tiếp khi cần.

// Quay lại
Navigator.pop(context);

NAMED ROUTES

Định nghĩa

Thay vì tạo route mới trong mỗi push(), khai báo routes bằng tên. Quản lý dễ dàng hơn trong ứng dụng lớn.

Cấu hình

MaterialApp(
  initialRoute: '/',
  routes: {
    '/': (context) => HomePage(),
    '/login': (context) => LoginPage(),
    '/profile': (context) => ProfilePage(),
  },
);

Sử dụng

// Điều hướng đến Login
Navigator.pushNamed(context, '/login');

// Quay lại
Navigator.pop(context);

// Thay thế trang hiện tại
Navigator.pushReplacementNamed(
  context, '/home');

// Xóa stack và đi đến trang mới
Navigator.pushNamedAndRemoveUntil(
  context, '/dashboard', (route) => false);

DYNAMIC ROUTE — onGenerateRoute

Giới thiệu

onGenerateRoute hữu ích khi cần truyền data hoặc thực hiện logic kiểm tra phức tạp.

Được gọi khi route không được tìm thấy trong routes map.

Khi nào dùng?

  • Truyền tham số qua route (VD: product ID)
  • Kiểm tra authentication trước navigation
  • Tạo routes động dựa trên user role

Ví dụ

MaterialApp(
  onGenerateRoute: (settings) {
    if (settings.name == '/product') {
      final id = settings.arguments as int;
      return MaterialPageRoute(
        builder: (context) =>
          ProductPage(id: id),
      );
    }
    return null;
  },
);

TRUYỀN DATA QUA ROUTE

Cách 1: Constructor

Truyền data trực tiếp qua constructor của Widget đích.

Navigator.push(
  context,
  MaterialPageRoute(
    builder: (context) =>
      DetailPage(product: myProduct),
  ),
);

Đơn giản, trực tiếp — phù hợp cho data đơn giản.

Cách 2: settings.arguments

Truyền data qua arguments object, nhận qua ModalRoute.of(context).settings.arguments.

// Gửi
Navigator.pushNamed(
  context,
  '/detail',
  arguments: product,
);

// Nhận
final product =
  ModalRoute.of(context)!.settings.arguments
  as Product;

Phù hợp cho Named Routes và Dynamic Routing.

STATIC ROUTE CONFIGURATION

Cấu hình tĩnh

Khai báo tất cả routes trong MaterialApp.routes — gọi là "Static" vì các routes được xác định sẵn tại thời điểm khởi tạo app.

void main() {
  runApp(MaterialApp(
    initialRoute: '/',
    routes: {
      '/': (context) => HomePage(),
      '/about': (context) => AboutPage(),
      '/contact': (context) => ContactPage(),
    },
  ));
}

Điều hướng

// Từ bất kỳ đâu trong app
Navigator.pushNamed(context, '/about');

// Từ another screen
Navigator.pushNamed(
  context,
  RouteNames.about, // Enum approach
);

Enum cho route names

Dùng Enum thay vì string literals để tránh typo và dễ refactor.

enum RouteNames { home, about, contact }

Navigator.pushNamed(
  context,
  RouteNames.about.name,
);

GIỚI THIỆU GOROUTER

Tại sao cần GoRouter?

Navigator 1.0 có nhiều hạn chế trong ứng dụng lớn. GoRouter là routing package chính thức từ Flutter team.

flutter pub add go_router

Ưu điểm

  • Declarative routing — route là data, không phải widget
  • Hỗ trợ deep linking tự động (web URL)
  • Redirect/guards dễ dàng
  • Nested routes — route tree có thứ bậc

Ví dụ cơ bản

final router = GoRouter(
  initialLocation: '/',
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) =>
        HomePage(),
    ),
    GoRoute(
      path: '/login',
      builder: (context, state) =>
        LoginPage(),
    ),
  ],
);

GOROUTER — NAVIGATE VÀ BUILDCONTEXT

Navigate với GoRouter

// Điều hướng đơn giản
context.go('/home');

// Đẩy route mới lên stack
context.push('/product/42');

// Quay lại
context.pop();

// Thay thế route hiện tại
context.replace('/fallback');

go() vs push() vs context.go()

  • go(): thay thế toàn bộ stack (như Navigator.pushReplacement)
  • push(): thêm route mới lên stack
  • context.go(): điều hướng từ BuildContext

Tích hợp MaterialApp

void main() {
  runApp(
    MaterialApp.router(
      routerConfig: router,
    ),
  );
}

// Hoặc dùng GoRouter builder
MaterialApp.router(
  title: 'My App',
  routerConfig: GoRouter(
    routes: [...],
  ),
);

✨ XU HƯỚNG HIỆN ĐẠI

go_router ^14.x tích hợp ShellRoute cho layout pattern phổ biến (bottom nav giữ nguyên khi chuyển tab).

PATH PARAMETERS — ROUTE ĐỘNG

Khai báo path parameter

Dùng :paramName trong path để truyền giá trị động — ví dụ: ID sản phẩm, username...

GoRoute(
  path: '/product/:id',
  builder: (context, state) {
    // Đọc path param
    final id = state.pathParameters['id'];
    return ProductPage(id: id!);
  },
),

Lưu ý

Path parameter luôn là String. Chuyển đổi kiểu (int, double) bằng int.tryParse(id!).

Navigate với tham số

// Truyền path param
context.push('/product/42');
// Đọc param
// URL: /product/42 → id='42'

// Nhiều params
GoRoute(
  path: '/users/:userId/posts/:postId',
  builder: (context, state) {
    final userId = state
      .pathParameters['userId'];
    final postId = state
      .pathParameters['postId'];
    return PostPage(userId!, postId!);
  },
),

QUERY PARAMETERS — EXTRA DATA

Query string

Thêm query parameters vào URL: /search?q=flutter&page=1. Dùng cho filters, pagination, search.

// Navigate với query
context.push(
  Uri(path: '/search',
    queryParameters: {
      'q': 'flutter',
      'sort': 'price',
    }).toString()
);

Đọc Query Parameters

// Trong GoRoute builder
final q = state
  .uri.queryParameters['q'];
final page = state
  .uri.queryParameters['page'] ?? '1';

Extra state object

Dùng extra để truyền object phức tạp qua route (không serialize được).

// Gửi object
context.push(
  '/detail',
  extra: myProduct,
);

// Nhận object
GoRoute(
  path: '/detail',
  builder: (context, state) {
    final product = state.extra
      as Product?;
    return DetailPage(product: product);
  },
),

Lưu ý

extra không serialize → không dùng được với deep link trên web. Dùng path/query params thay thế.

NESTED ROUTES — ROUTE CÓ THỨ BẬC

Khái niệm

Nested routes cho phép route con nằm trong route cha — parent widget giữ nguyên khi child route thay đổi. Rất phù hợp cho bottom navigation.

GoRoute(
  path: '/shop',
  builder: (context, state) =>
    ShopLayout(), // Giữ nguyên
  routes: [
    // Nested route
    GoRoute(
      path: 'products',
      builder: (context, state) =>
        ProductsPage(),
    ),
    GoRoute(
      path: 'cart',
      builder: (context, state) =>
        CartPage(),
    ),
  ],
),

ShellRoute

ShellRoute tự động bọc child routes trong parent widget — layout wrapper đơn giản hơn.

ShellRoute(
  builder: (context, state, child) {
    // child là route hiện tại
    return AppShell(child: child);
  },
  routes: [...],
)

Ứng dụng phổ biến

Bottom navigation: 4 tabs (Home, Search, Cart, Profile). Mỗi tab có nhiều screens con — ShellRoute giữ bottom nav cố định.

REDIRECT VÀ AUTHENTICATION GUARDS

Tại sao cần Redirect?

Chặn truy cập routes không được phép — ví dụ: redirect về login nếu chưa đăng nhập.

GoRoute(
  path: '/profile',
  redirect: (context, state) {
    final isLoggedIn =
      UserService().isAuthenticated;
    if (!isLoggedIn) {
      return '/login';
    }
    return null; // Cho phép truy cập
  },
  builder: (context, state) =>
    ProfilePage(),
),

Redirect toàn app

Đặt redirect ở GoRouter root — tất cả routes đều bị kiểm tra.

final router = GoRouter(
  redirect: (context, state) {
    final isAuth = authProvider.isAuth;
    final isLogin = state.matchedLocation
      == '/login';

    // Chưa login, không phải trang login
    if (!isAuth && !isLogin) {
      return '/login';
    }
    // Đã login, ở trang login → về home
    if (isAuth && isLogin) {
      return '/dashboard';
    }
    return null;
  },
  routes: [...],
);

Kết hợp Riverpod

Dùng ref.read(authProvider) bên trong redirect để truy cập trạng thái auth từ Riverpod.

GO ROUTER — ERROR HANDLING

404 Not Found Page

Dùng errorBuilder hoặc route có path: '*' để bắt route không tồn tại.

GoRoute(
  path: '*',
  builder: (context, state) =>
    ErrorPage(
      error: state.error,
    ),

ErrorBuilder toàn app

GoRouter(
  errorBuilder: (ctx, state) =>
    Scaffold(
      body: Center(
        Text('404: ${state.uri}')),
    ),
  routes: [...],
)

PopException Handling

Khi Navigator.pop() được gọi ở root — app sẽ crash. Xử lý bằng Router.navigatorKey.

// Bắt pop ở root level
final rootNavigatorKey =
  GlobalKey<NavigatorState>();
final _router = GoRouter(
  navigatorKey: rootNavigatorKey,
  routes: [...],
);

Lưu ý

Trong ShellRoute, dùng parentNavigatorKey thay vì navigatorKey để pop đúng stack.

DEEP LINKING — LIÊN KẾT TRÊN WEB

Khái niệm Deep Link

Deep link là URL có thể mở trực tiếp ứng dụng: myapp://shop/products/42 hoặc web URL.

1

Android — intent-filter

Cấu hình trong AndroidManifest.xml

2

iOS — URL Schemes / Universal Links

Cấu hình trong Xcode — Association File

3

Web — App Link / link handling

<meta> tags hoặc go_router Web

Cấu hình GoRouter cho Web

// URL đầy đủ từ web host
GoRouter(
  initialLocation: '/',
  routes: [
    GoRoute(path: '/', ...),
    GoRoute(path: '/shop/:id', ...),
  ],

URL trên web

  • example.com/ → HomePage
  • example.com/product/42 → ProductPage(id=42)
  • example.com/search?q=flutter → SearchPage

BOTTOM NAVIGATION VỚI GOROUTER

ShellRoute cho Bottom Nav

ShellRoute giữ bottom navigation cố định khi tab con thay đổi.

GoRoute(
  path: '/app',
  builder: (context, state) =>
    MainShell(), // Chứa BottomNav
  routes: [
    GoRoute(path: 'home', ...),
    GoRoute(path: 'search', ...),
    GoRoute(path: 'cart', ...),
    GoRoute(path: 'profile', ...),
  ],
)

StatefulShellRoute (GoRouter 14+)

StatefulShellRoute.indexedStack — giữ state của mỗi tab khi chuyển.

StatefulShellRoute.indexedStack(
  builder: (ctx, state, navigationShell) {
    // navigationShell.index = tab hiện tại
    return MainShell(navigationShell);
  },
  branches: [
    StatefulShellBranch(routes: [homeRoute]),
    StatefulShellBranch(routes: [searchRoute]),
    StatefulShellBranch(routes: [cartRoute]),
  ],
)

Lưu ý

StatefulShellRoute yêu cầu GoRouter ^14.0.0. Cập nhật pubspec.yaml trước khi dùng.

NAMED ROUTES VÀ URL HELPERS

Route Constants

Tránh magic strings — dùng constants hoặc extension để define route names.

// routes.dart
abstract class AppRoutes {
  static const home = '/';\br>   static const login = '/login';\br>   static const product = '/product/:id';\br>   static const cart = '/cart';\br>   static const profile = '/profile';\br> }

// Sử dụng
context.go(AppRoutes.home);

URL Builder Helpers

Tạo URL với params một cách an toàn — tránh typo và refactor dễ dàng.

// Extension
extension GoRouteX on String {
  Uri toGoUrl({Map<String, String>?
    params,
    Map<String, String>? query}) {
    var path = this;
    params?.forEach((k, v) {
      path = path.replaceAll(':$k', v);
    });
    return Uri(path: path,
      queryParameters: query);
  }
}

// Sử dụng
'/product/:id'.toGoUrl(
  params: {'id': '42'},
  query: {'color': 'red'},
);

Lưu ý

GoRouter ^14 có named routes built-in — dùng router.namedLocation('product', pathParameters: {'id': '42'}).
