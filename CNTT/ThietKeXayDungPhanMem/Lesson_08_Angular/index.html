ANGULAR LÀ GÌ?

Angular là TypeScript-based frontend framework, maintained by Google. Dùng cho Single Page Applications (SPA). [angular.io]

Key Features:

  • Component-Based — modular, reusable components
  • TypeScript — static typing, better tooling
  • Two-Way Data Binding — sync model ↔ view
  • Dependency Injection — built-in DI system
  • Routing — SPA navigation (Angular Router)
  • RxJS — reactive programming với Observables
  • CLI — generate components, services, modules

Cài đặt:

# Install Node.js (LTS)
# Install Angular CLI
npm install -g @angular/cli

# Create project
ng new my-app
cd my-app

# Start dev server

# → http://localhost:4200

TYPESCRIPT — NỀN TẢNG CỦA ANGULAR

TypeScript = JavaScript + Static Typing. Microsoft phát triển, Angular dùng chính thức. [typescriptlang.org]

Tại sao TypeScript?

  • Type safety — phát hiện lỗi compile-time
  • IDE support — autocomplete, refactoring
  • Modern features — interfaces, generics, enums
  • Backward compatible — JS hợp lệ là TS
  • Compile to JS — chạy mọi browser

COMPONENT LIFECYCLE HOOKS

Angular gọi các method đặc biệt trong vòng đời component — gọi là lifecycle hooks.

HookKhi nào gọi
ngOnChangesKhi @Input thay đổi
ngOnInitSau constructor + OnChanges đầu
ngDoCheckMọi change detection cycle
ngAfterContentInitSau content projection
ngAfterContentCheckedSau check content
ngAfterViewInitSau view init
ngAfterViewCheckedSau check view
ngOnDestroyTrước khi destroy component

VD sử dụng:

@Component({...})
export class UserListComponent
    implements OnInit, OnDestroy {

  users: User[] = [];
  private subscription: Subscription;

  constructor(
    private userService: UserService) {}

  ngOnInit(): void {
    // Init logic — gọi API
    this.subscription = this.userService
      .getAll()
      .subscribe(data => this.users = data);
  }

  ngOnDestroy(): void {
    // Cleanup — unsubscribe
    this.subscription?.unsubscribe();
  }
}

⚠️ Luôn unsubscribe trong ngOnDestroy để tránh memory leak.

export class UserListComponent {
  users: User[] = [];

  handleDelete(userId: number) {
    this.userService.delete(userId)
      .subscribe(() => {
        this.users = this.users.filter(
          u => u.id !== userId);
      });
  }
}

SERVICES & DEPENDENCY INJECTION

Services chứa business logic, share data giữa components, gọi API. Inject vào components qua constructor.

Tạo service:

ng generate service services/user
# Tạo: user.service.ts
@Injectable({
  providedIn: 'root'  // Singleton toàn app
})
export class UserService {
  private apiUrl = 'http://localhost:8080/api/users';
  private currentUser$ =
    new BehaviorSubject<User | null>(null);

  constructor(private http: HttpClient) {}

  getCurrentUser(): Observable<User | null> {
    return this.currentUser$.asObservable();
  }

  setCurrentUser(user: User) {
    this.currentUser$.next(user);
  }

  getAll(): Observable<User[]> {
    return this.http.get<User[]>(this.apiUrl);
  }
}

Provider scopes:

'platform'Multiple Angular apps
'any'Per lazy module
Module providersPer module
Component providersPer component instance

Custom Pipe:

@Pipe({
  name: 'truncate',
  standalone: true
})
export class TruncatePipe
    implements PipeTransform {

  transform(value: string,
      limit: number = 50,
      suffix: string = '...'): string {
    if (!value) return '';
    if (value.length <= limit) return value;
    return value.substring(0, limit) + suffix;
  }
}

// Sử dụng
<p>{{ description | truncate:100 }}</p>

CUSTOM DIRECTIVES

Attribute Directive:

@Directive({
  selector: '[appHighlight]',
  standalone: true
})
export class HighlightDirective {
  @Input() appHighlight = 'yellow';

  constructor(
    private el: ElementRef,
    private renderer: Renderer2) {}

  @HostListener('mouseenter')
  onMouseEnter() {
    this.renderer.setStyle(
      this.el.nativeElement,
      'background-color',
      this.appHighlight);
  }

  @HostListener('mouseleave')
  onMouseLeave() {
    this.renderer.setStyle(
      this.el.nativeElement,
      'background-color', null);
  }
}

// Sử dụng

Structural Directive:

@Directive({
  selector: '[appHasRole]',
  standalone: true
})
export class HasRoleDirective {
  @Input() set appHasRole(role: string) {
    if (this.authService.hasRole(role)) {
      this.viewContainer.createEmbeddedView(
        this.templateRef);
    } else {
      this.viewContainer.clear();
    }
  }

  constructor(
    private templateRef: TemplateRef<any>,
    private viewContainer: ViewContainerRef,
    private authService: AuthService) {}
}

// Sử dụng

  Delete
</button>

import { FormBuilder, FormGroup,
  Validators } from '@angular/forms';

@Component({...})
export class RegisterComponent
    implements OnInit {

  registerForm!: FormGroup;

  constructor(
    private fb: FormBuilder,
    private authService: AuthService) {}

  ngOnInit() {
    this.registerForm = this.fb.group({
      email: ['',
        [Validators.required, Validators.email]],
      password: ['',
        [Validators.required,
        Validators.minLength(8)]],
      confirmPassword: ['',
        [Validators.required]],
      fullName: ['',
        [Validators.required,
        Validators.maxLength(100)]],
      acceptTerms: [false,
        Validators.requiredTrue]
    }, { validators: this.passwordMatchValidator });
  }

  onSubmit() {
    if (this.registerForm.invalid) return;
    this.authService.register(
      this.registerForm.value).subscribe();
  }
}

ROUTE PARAMS & GUARDS

Đọc route params:

@Component({...})
export class CourseDetailComponent
    implements OnInit {

  course?: Course;

  constructor(
    private route: ActivatedRoute,
    private courseService: CourseService) {}

  ngOnInit() {
    // Snapshot (1 lần)
    const id = this.route.snapshot
      .paramMap.get('id');

    // Hoặc subscribe (reactive)
    this.route.paramMap.subscribe(params => {
      const id = +params.get('id')!;
      this.courseService.getById(id)
        .subscribe(c => this.course = c);
    });

    // Query params
    this.route.queryParams.subscribe(qp => {
      console.log('ref:', qp['ref']);
    });
  }
}

Auth Guard:

@Injectable({ providedIn: 'root' })
export class AuthGuard implements CanActivate {

  constructor(
    private authService: AuthService,
    private router: Router) {}

  canActivate(
      route: ActivatedRouteSnapshot,
      state: RouterStateSnapshot): boolean {
    if (this.authService.isLoggedIn()) {
      return true;
    }

    this.router.navigate(['/login'],
      { queryParams: {
        returnUrl: state.url } });
    return false;
  }
}

Role Guard:

@Injectable({ providedIn: 'root' })
export class AdminGuard implements CanActivate {
  constructor(
    private authService: AuthService) {}

  canActivate(): boolean {
    return this.authService
      .hasRole('ADMIN');
  }
}

ANGULAR SIGNALS — REACTIVITY MỚI

Signals (Angular 16+) là cách reactive mới — đơn giản hơn RxJS cho state management.

Tạo signal:

import { signal, computed, effect }
  from '@angular/core';

export class CounterComponent {
  // Writable signal
  count = signal(0);

  // Computed (derived)
  doubled = computed(() => this.count() * 2);

  isEven = computed(() =>
    this.count() % 2 === 0);

  // Effect (side effect)
  constructor() {
    effect(() => {
      console.log('Count:',
        this.count());
    });
  }

  increment() {
    this.count.update(v => v + 1);
  }

  reset() {
    this.count.set(0);
  }
}

Template:

<div>

CHANGE DETECTION STRATEGY

Angular tự động phát hiện thay đổi và cập nhật DOM. Có 2 strategies:

Default:

  • Check toàn bộ component tree mỗi event
  • Đơn giản, hoạt động luôn đúng
  • Có thể chậm với nhiều components

OnPush:

  • Chỉ check khi: @Input thay đổi reference, event xảy ra trong component, async pipe emit
  • Nhanh hơn nhiều
  • Yêu cầu immutable data
@Component({
  selector: 'app-user-list',
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `
    @for (user of users(); track user.id) {
      <app-user-card [user]="user"/>
    }
  `
})
export class UserListComponent {
  users = signal<User[]>([]);
}

Manual trigger:

constructor(private cdr: ChangeDetectorRef) {}

updateData() {
  this.data = [...this.data, newItem];
  this.cdr.markForCheck();
  // hoặc
  this.cdr.detectChanges();
}

TrackBy với ngFor:

<li *ngFor="let u of users; trackBy: trackById">
  {{ u.name }}
</li>

trackById(index: number, user: User) {
  return user.id;

STATE MANAGEMENT — NGRX

NgRx = Redux pattern cho Angular — quản lý state toàn app theo flux pattern. Phù hợp app lớn, phức tạp.

Concepts:

  • Store — single source of truth
  • Actions — events mô tả "có gì xảy ra"
  • Reducers — pure functions update state
  • Selectors — read state
  • Effects — side effects (HTTP calls)

VD Action:

export const loadUsers =
  createAction('[User] Load Users');

export const loadUsersSuccess = createAction(
  '[User] Load Success',
  props<{ users: User[] }>()
);

Reducer:

export const userReducer = createReducer(
  initialState,
  on(loadUsers, state => ({
    ...state,
    loading: true
  })),
  on(loadUsersSuccess, (state, { users }) => ({
    ...state,
    users,
    loading: false
  }))
);

Effect (async):

loadUsers$ = createEffect(() =>
  this.actions$.pipe(
    ofType(loadUsers),
    mergeMap(() =>
      this.userService.getAll().pipe(
        map(users => loadUsersSuccess({ users })),
        catchError(err => of(loadUsersFailure({ err })))
      )
    )
  )
);

Alternative nhẹ hơn: NgRx Component Store, Akita, Signals.

LAZY LOADING — TỐI ƯU PERFORMANCE

Lazy Loading chỉ tải module khi user navigate đến route đó — giảm initial bundle size, app load nhanh hơn.

Cấu hình route:

const routes: Routes = [
  { path: '', component: HomeComponent },

  // Lazy load admin module
  {
    path: 'admin',
    loadChildren: () =>
      import('./admin/admin.module')
        .then(m => m.AdminModule)
  },

  // Lazy load standalone component
  {
    path: 'reports',
    loadComponent: () =>
      import('./reports/reports.component')
        .then(c => c.ReportsComponent)
  }
];

Preloading strategies:

// Preload tất cả lazy modules sau initial load
RouterModule.forRoot(routes, {
  preloadingStrategy: PreloadAllModules
})

// Hoặc custom strategy
@Injectable()
export class CustomPreload
    implements PreloadingStrategy {
  preload(route: Route, fn: () => Observable<any>) {
    return route.data?.['preload']
      ? fn() : EMPTY;
  }
}

// Trong route
{ path: 'admin',
  loadChildren: ...,
  data: { preload: true } }

Nên làm:

  • ✅ OnPush change detection cho performance
  • ✅ Async pipe thay vì manual subscribe
  • ✅ TrackBy trong @for/*ngFor
  • ✅ Lazy loading cho feature modules

Tránh:

  • ❌ Logic phức tạp trong template
  • ❌ Function calls trong template (chạy mỗi CD)
  • ❌ Mutate input arrays/objects
  • ❌ any type — dùng unknown hoặc proper type

  • ❌ Hardcode URLs — dùng environment.ts

Task Service:

@Injectable({ providedIn: 'root' })
export class TaskService {
  private apiUrl = '/api/tasks';

  constructor(private http: HttpClient) {}

  getAll(): Observable<Task[]> {
    return this.http.get<Task[]>(this.apiUrl);
  }

  create(task: Task): Observable<Task> {
    return this.http.post<Task>(
      this.apiUrl, task);
  }

  update(id: number, task: Task)
      : Observable<Task> {
    return this.http.put<Task>(
      `${this.apiUrl}/${id}`, task);
  }

  delete(id: number): Observable<void> {
    return this.http.delete<void>(
      `${this.apiUrl}/${id}`);
  }

  toggleComplete(id: number)
      : Observable<Task> {
    return this.http.patch<Task>(
      `${this.apiUrl}/${id}/toggle`, {});
  }
}
