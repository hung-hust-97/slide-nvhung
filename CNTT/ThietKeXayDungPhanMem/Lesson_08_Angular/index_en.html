WHAT IS ANGULAR?

Angular is a TypeScript-based frontend framework, maintained by Google. Used for Single Page Applications (SPA). [angular.io]

Key Features:

  • Component-Based — modular, reusable components
  • TypeScript — static typing, better tooling
  • Two-Way Data Binding — sync model ↔ view
  • Dependency Injection — built-in DI system
  • Routing — SPA navigation (Angular Router)
  • RxJS — reactive programming with Observables
  • CLI — generate components, services, modules

TYPESCRIPT — THE FOUNDATION OF ANGULAR

TypeScript = JavaScript + Static Typing. Developed by Microsoft, officially used by Angular. [typescriptlang.org]

Why TypeScript?

  • Type safety — catch errors at compile-time
  • IDE support — autocomplete, refactoring
  • Modern features — interfaces, generics, enums
  • Backward compatible — valid JS is valid TS
  • Compile to JS — runs in any browser

COMPONENT LIFECYCLE HOOKS

Angular calls special methods during a component's lifecycle — called lifecycle hooks.

HookWhen called
ngOnChangesWhen @Input changes
ngOnInitAfter constructor + first OnChanges
ngDoCheckEvery change detection cycle
ngAfterContentInitAfter content projection
ngAfterContentCheckedAfter content check
ngAfterViewInitAfter view init
ngAfterViewCheckedAfter view check
ngOnDestroyBefore component is destroyed

Usage example:

@Component({...})
export class UserListComponent
    implements OnInit, OnDestroy {

  users: User[] = [];
  private subscription: Subscription;

  constructor(
    private userService: UserService) {}

  ngOnInit(): void {
    // Init logic — call API
    this.subscription = this.userService
      .getAll()
      .subscribe(data => this.users = data);
  }

  ngOnDestroy(): void {
    // Cleanup — unsubscribe
    this.subscription?.unsubscribe();
  }
}

⚠️ Always unsubscribe in ngOnDestroy to avoid memory leaks.

SERVICES & DEPENDENCY INJECTION

Services contain business logic, share data between components, and call APIs. Injected into components via constructor.

Create service:

ng generate service services/user
# Creates: user.service.ts
@Injectable({
  providedIn: 'root'  // Singleton for entire app
})
export class UserService {
  private apiUrl = 'http://localhost:8080/api/users';
  private currentUser$ =
    new BehaviorSubject<User | null>(null);

  constructor(private http: HttpClient) {}

  getCurrentUser(): Observable<User | null> {
    return this.currentUser$.asObservable();
  }

  setCurrentUser(user: User) {
    this.currentUser$.next(user);
  }

  getAll(): Observable<User[]> {
    return this.http.get<User[]>(this.apiUrl);
  }
}

'root'Singleton, entire app
'platform'Multiple Angular apps
'any'Per lazy module
Module providersPer module
Component providersPer component instance

Custom Pipe:

@Pipe({
  name: 'truncate',
  standalone: true
})
export class TruncatePipe
    implements PipeTransform {

  transform(value: string,
      limit: number = 50,
      suffix: string = '...'): string {
    if (!value) return '';
    if (value.length <= limit) return value;
    return value.substring(0, limit) + suffix;
  }
}

// Usage
<p>{{ description | truncate:100 }}</p>

CUSTOM DIRECTIVES

Attribute Directive:

@Directive({
  selector: '[appHighlight]',
  standalone: true
})
export class HighlightDirective {
  @Input() appHighlight = 'yellow';

  constructor(
    private el: ElementRef,
    private renderer: Renderer2) {}

  @HostListener('mouseenter')
  onMouseEnter() {
    this.renderer.setStyle(
      this.el.nativeElement,
      'background-color',
      this.appHighlight);
  }

  @HostListener('mouseleave')
  onMouseLeave() {
    this.renderer.setStyle(
      this.el.nativeElement,
      'background-color', null);
  }
}

@Directive({
  selector: '[appHasRole]',
  standalone: true
})
export class HasRoleDirective {
  @Input() set appHasRole(role: string) {
    if (this.authService.hasRole(role)) {
      this.viewContainer.createEmbeddedView(
        this.templateRef);
    } else {
      this.viewContainer.clear();
    }
  }

  constructor(
    private templateRef: TemplateRef<any>,
    private viewContainer: ViewContainerRef,
    private authService: AuthService) {}
}

import { FormBuilder, FormGroup,
  Validators } from '@angular/forms';

@Component({...})
export class RegisterComponent
    implements OnInit {

  registerForm!: FormGroup;

  constructor(
    private fb: FormBuilder,
    private authService: AuthService) {}

  ngOnInit() {
    this.registerForm = this.fb.group({
      email: ['',
        [Validators.required, Validators.email]],
      password: ['',
        [Validators.required,
        Validators.minLength(8)]],
      confirmPassword: ['',
        [Validators.required]],
      fullName: ['',
        [Validators.required,
        Validators.maxLength(100)]],
      acceptTerms: [false,
        Validators.requiredTrue]
    }, { validators: this.passwordMatchValidator });
  }

  onSubmit() {
    if (this.registerForm.invalid) return;
    this.authService.register(
      this.registerForm.value).subscribe();
  }
}

ROUTE PARAMS & GUARDS

Reading route params:

@Component({...})
export class CourseDetailComponent
    implements OnInit {

  course?: Course;

  constructor(
    private route: ActivatedRoute,
    private courseService: CourseService) {}

  ngOnInit() {
    // Snapshot (one-time)
    const id = this.route.snapshot
      .paramMap.get('id');

    // Or subscribe (reactive)
    this.route.paramMap.subscribe(params => {
      const id = +params.get('id')!;
      this.courseService.getById(id)
        .subscribe(c => this.course = c);
    });

    // Query params
    this.route.queryParams.subscribe(qp => {
      console.log('ref:', qp['ref']);
    });
  }
}

Auth Guard:

@Injectable({ providedIn: 'root' })
export class AuthGuard implements CanActivate {

  constructor(
    private authService: AuthService,
    private router: Router) {}

  canActivate(
      route: ActivatedRouteSnapshot,
      state: RouterStateSnapshot): boolean {
    if (this.authService.isLoggedIn()) {
      return true;
    }

    this.router.navigate(['/login'],
      { queryParams: {
        returnUrl: state.url } });
    return false;
  }
}

ANGULAR SIGNALS — NEW REACTIVITY

Signals (Angular 16+) is the new reactive approach — simpler than RxJS for state management.

Create signal:

import { signal, computed, effect }
  from '@angular/core';

export class CounterComponent {
  // Writable signal
  count = signal(0);

  // Computed (derived)
  doubled = computed(() => this.count() * 2);

  isEven = computed(() =>
    this.count() % 2 === 0);

  // Effect (side effect)
  constructor() {
    effect(() => {
      console.log('Count:',
        this.count());
    });
  }

  increment() {
    this.count.update(v => v + 1);
  }

  reset() {
    this.count.set(0);
  }
}

Template:

<div>
  <p>Count: {{ count() }}</p>
  <p>Doubled: {{ doubled() }}</p>
  <p>{{ isEven() ? 'Even' : 'Odd' }}</p>

  <button (click)="increment()">+1</button>
  <button (click)="reset()">Reset</button>
</div>

CHANGE DETECTION STRATEGY

Angular automatically detects changes and updates the DOM. There are 2 strategies:

Default:

  • Checks entire component tree on every event
  • Simple, always works correctly
  • Can be slow with many components

OnPush:

  • Only checks when: @Input reference changes, event occurs within component, async pipe emits
  • Much faster
  • Requires immutable data
@Component({
  selector: 'app-user-list',
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `
    @for (user of users(); track user.id) {
      <app-user-card [user]="user"/>
    }
  `
})
export class UserListComponent {
  users = signal<User[]>([]);
}

Manual trigger:

constructor(private cdr: ChangeDetectorRef) {}

updateData() {
  this.data = [...this.data, newItem];
  this.cdr.markForCheck();
  // or
  this.cdr.detectChanges();
}

TrackBy with ngFor:

<li *ngFor="let u of users; trackBy: trackById">
  {{ u.name }}
</li>

trackById(index: number, user: User) {
  return user.id;
}
// Avoids re-rendering the entire list
// when only 1 item changes

STATE MANAGEMENT — NGRX

NgRx = Redux pattern for Angular — manages app-wide state using the flux pattern. Suitable for large, complex apps.

Concepts:

  • Store — single source of truth
  • Actions — events describing "what happened"
  • Reducers — pure functions that update state
  • Selectors — read state
  • Effects — side effects (HTTP calls)

Example Action:

export const loadUsers =
  createAction('[User] Load Users');

export const loadUsersSuccess = createAction(
  '[User] Load Success',
  props<{ users: User[] }>()
);

Reducer:

export const userReducer = createReducer(
  initialState,
  on(loadUsers, state => ({
    ...state,
    loading: true
  })),
  on(loadUsersSuccess, (state, { users }) => ({
    ...state,
    users,
    loading: false
  }))
);

Effect (async):

loadUsers$ = createEffect(() =>
  this.actions$.pipe(
    ofType(loadUsers),
    mergeMap(() =>
      this.userService.getAll().pipe(
        map(users => loadUsersSuccess({ users })),
        catchError(err => of(loadUsersFailure({ err })))
      )
    )
  )
);

Lighter alternatives: NgRx Component Store, Akita, Signals.

LAZY LOADING — PERFORMANCE OPTIMIZATION

Lazy Loading only loads a module when the user navigates to that route — reduces initial bundle size, app loads faster.

Route configuration:

const routes: Routes = [
  { path: '', component: HomeComponent },

  // Lazy load admin module
  {
    path: 'admin',
    loadChildren: () =>
      import('./admin/admin.module')
        .then(m => m.AdminModule)
  },

  // Lazy load standalone component
  {
    path: 'reports',
    loadComponent: () =>
      import('./reports/reports.component')
        .then(c => c.ReportsComponent)
  }
];

Preloading strategies:

// Preload all lazy modules after initial load
RouterModule.forRoot(routes, {
  preloadingStrategy: PreloadAllModules
})

// Or custom strategy
@Injectable()
export class CustomPreload
    implements PreloadingStrategy {
  preload(route: Route, fn: () => Observable<any>) {
    return route.data?.['preload']
      ? fn() : EMPTY;
  }
}

// In route
{ path: 'admin',
  loadChildren: ...,
  data: { preload: true } }

ANGULAR ANIMATIONS

Angular Animations API provides a DSL for creating animations based on the Web Animations API.

Setup:

import { provideAnimations } from
  '@angular/platform-browser/animations';

bootstrapApplication(AppComponent, {
  providers: [provideAnimations()]
});

Define animation:

import { trigger, state, style,
  animate, transition } from
  '@angular/animations';

@Component({
  animations: [
    trigger('fadeInOut', [
      state('void', style({
        opacity: 0,
        transform: 'translateY(-20px)'
      })),
      transition(':enter, :leave', [
        animate('300ms ease-in-out')
      ])
    ])
  ]
})
export class NotificationComponent {}

Usage:

<div *ngIf="visible"
  [@fadeInOut]>
  Notification message
</div>

Complex animation:

trigger('listAnimation', [
  transition('* => *', [
    query(':enter', [
      style({ opacity: 0, transform:
        'translateX(-100px)' }),
      stagger(100, [
        animate('500ms ease-out',
          style({ opacity: 1, transform:
            'translateX(0)' }))
      ])
    ], { optional: true }),
    query(':leave', [
      animate('300ms',
        style({ opacity: 0 }))
    ], { optional: true })
  ])
])

SERVER-SIDE RENDERING (SSR)

Angular Universal allows rendering Angular apps on the server instead of the browser → better SEO, faster FCP.

Why SSR?

  • SEO — Google bot reads pre-rendered HTML
  • First Contentful Paint is faster
  • Social media preview (Open Graph)
  • Slow devices — server does the heavy lifting

Setup:

ng add @angular/ssr

# Creates:
# - server.ts (Express server)
# - main.server.ts
# - app.config.server.ts
# - tsconfig.server.json

Build & Run SSR:

# Build
ng build --ssr

# Run
node dist/my-app/server/server.mjs

# Or Docker
FROM node:20-alpine
WORKDIR /app
COPY dist/my-app ./
EXPOSE 4000
CMD ["node", "server/server.mjs"]

Caveats:

  • No window/document on server — check isPlatformBrowser
  • localStorage not available — use cookies
  • setTimeout can block rendering
  • Memory leaks — requests not cleaned up
✨ MODERN TRENDS

Angular 17+ Hydration — server renders HTML, client "hydrates" for interactivity — best of both worlds.

ANGULAR BEST PRACTICES

Do:

  • ✅ OnPush change detection for performance
  • ✅ Async pipe instead of manual subscribe
  • ✅ TrackBy in @for/*ngFor
  • ✅ Lazy loading for feature modules
  • ✅ Reactive Forms for complex forms
  • ✅ Smart/Dumb components pattern
  • ✅ Strict TypeScript mode
  • ✅ Environment files for config
  • ✅ Standalone components (Angular 17+)
  • ✅ Signals for local state

Don't:

  • ❌ Complex logic in templates
  • ❌ Function calls in templates (runs every CD)
  • ❌ Mutate input arrays/objects
  • ❌ any type — use unknown or proper type
  • ❌ Subscribe in templates manually
  • ❌ Forget to unsubscribe → memory leak
  • ❌ Direct DOM manipulation — use Renderer2
  • ❌ API calls in constructor
  • ❌ Hardcode URLs — use environment.ts
✨ MODERN TRENDS

Angular 18+: Zoneless change detection (no Zone.js) — peak performance, requires Signals.

PROJECT ASSIGNMENT — TO-DO LIST APP

Requirements:

  • CRUD tasks — add, edit, delete, mark as complete
  • Filter — All / Active / Completed
  • Persist data — call Spring Boot API
  • Routing — multiple pages
  • Login — JWT auth

Structure:

src/app/
  ├── components/
  │   ├── task-list/
  │   ├── task-item/
  │   └── task-form/
  ├── services/
  │   ├── task.service.ts
  │   └── auth.service.ts
  ├── models/
  │   └── task.model.ts
  ├── guards/
  │   └── auth.guard.ts
  └── interceptors/
      └── auth.interceptor.ts

Task Service:

@Injectable({ providedIn: 'root' })
export class TaskService {
  private apiUrl = '/api/tasks';

  constructor(private http: HttpClient) {}

  getAll(): Observable<Task[]> {
    return this.http.get<Task[]>(this.apiUrl);
  }

  create(task: Task): Observable<Task> {
    return this.http.post<Task>(
      this.apiUrl, task);
  }

  update(id: number, task: Task)
      : Observable<Task> {
    return this.http.put<Task>(
      `${this.apiUrl}/${id}`, task);
  }

  delete(id: number): Observable<void> {
    return this.http.delete<void>(
      `${this.apiUrl}/${id}`);
  }

  toggleComplete(id: number)
      : Observable<Task> {
    return this.http.patch<Task>(
      `${this.apiUrl}/${id}/toggle`, {});
  }
}
