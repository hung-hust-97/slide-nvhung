RXJS — REACTIVE EXTENSIONS FOR JAVASCRIPT

RxJS is a library for reactive programming with Observables — handling asynchronous data as streams. [rxjs.dev]

Why RxJS?

  • Declarative — focus on "what" instead of "how"
  • Async made easy — HTTP calls, events, timers
  • Composable — chain operators to transform data
  • Angular built-in — HttpClient returns Observable

Observable vs Promise:

PromiseObservable
Values1 valueMultiple values over time
LazyNoYes (only runs when subscribed)
CancelNoYes (unsubscribe)
OperatorsFewMany (map, filter, merge...)

Observable — Data Stream:

// Create Observable
const numbers$ = new Observable(observer => {
  observer.next(1);
  observer.next(2);
  observer.next(3);
  observer.complete();
});

// Subscribe to receive data
numbers$.subscribe({
  next: val => console.log(val),
  error: err => console.error(err),
  complete: () => console.log('Done!')
});

Common operators:

this.userService.getAll().pipe(
  map(users => users.filter(u => u.active)),
  catchError(err => {
    console.error(err);
    return of([]); // fallback
  })
).subscribe(users => this.users = users);

INTERCEPTORS & FULL-STACK INTEGRATION

HTTP Interceptor — auto-attach JWT:

@Injectable()
export class AuthInterceptor
    implements HttpInterceptor {

  intercept(req: HttpRequest<any>,
    next: HttpHandler): Observable<HttpEvent<any>> {

    const token = localStorage.getItem('jwt');
    if (token) {
      const cloned = req.clone({
        headers: req.headers.set(
          'Authorization', `Bearer ${token}`)
      });
      return next.handle(cloned);
    }
    return next.handle(req);
  }
}

// Register in app.module.ts:
providers: [{
  provide: HTTP_INTERCEPTORS,
  useClass: AuthInterceptor,
  multi: true
}]

PROCEDURAL VS REACTIVE PROGRAMMING

Procedural (Imperative):

Describes how to solve — step-by-step execution.

let count = 0;

button.addEventListener('click', () => {
  count++;
  if (count % 2 === 0) {
    console.log('Even click:', count);
  }
});

// Hard to test, hard to compose
// State scattered
// Side effects everywhere

Reactive (Declarative):

Describes what needs to happen — like a stream of values.

const buttonClicks$ = fromEvent(
  button, 'click');

buttonClicks$.pipe(
  scan((count) => count + 1, 0),
  filter((count) => count % 2 === 0),
  tap((count) => console.log(
    'Even click:', count))
).subscribe();

// Composable
// Declarative
// Easy to test
// Cancel-able

Benefits of Reactive:

  • Composable — easy to combine streams
  • Async — handles sync & async the same way
  • Memory safe — easy to unsubscribe
  • Testable — pure functions

SUBJECT, BEHAVIORSUBJECT, REPLAYSUBJECT

Subject = Observable + Observer. Can both emit and subscribe.

TypeCharacteristics
SubjectNo stored state, subscribers only receive emissions after subscribing
BehaviorSubjectStores current value, emits immediately on subscribe
ReplaySubjectStores last N values, replays on subscribe
AsyncSubjectOnly emits the last value on complete

BehaviorSubject example:

@Injectable({ providedIn: 'root' })
export class AuthService {
  private currentUser$ =
    new BehaviorSubject<User | null>(null);

  user$ = this.currentUser$.asObservable();

  login(user: User) {
    this.currentUser$.next(user);
  }

  logout() {
    this.currentUser$.next(null);
  }

  getCurrentUser(): User | null {
    return this.currentUser$.value;
  }
}

Usage in components:

@Component({
  template: `
    @if (user$ | async; as user) {
      <p>Welcome, {{ user.name }}</p>
      <button (click)="logout()">Logout</button>
    } @else {
      <a routerLink="/login">Login</a>
    }
  `
})
export class HeaderComponent {
  user$ = this.authService.user$;

  constructor(
    private authService: AuthService) {}

  logout() {
    this.authService.logout();
  }
}

const messages$ = new ReplaySubject<string>(3);

RXJS OPERATORS — TRANSFORMATION

Transformation operators:

OperatorDescription
mapTransform each value
mapToMap to a constant value
switchMapSwitch to inner observable, cancel previous
mergeMapMerge all inner observables
concatMapSequential, wait for previous to complete
exhaustMapIgnore new emissions while processing
scanStreaming reduce
bufferCollect multiple values into array

switchMap — search-as-you-type:

this.searchInput.valueChanges.pipe(
  debounceTime(300),  // Wait 300ms
  distinctUntilChanged(),  // Skip duplicates
  filter(text => text.length > 2),
  switchMap(text =>
    this.userService.search(text))
  // When user types again, cancel previous request
).subscribe(results => {
  this.results = results;
});

mergeMap vs concatMap:

// mergeMap - parallel uploads
files$.pipe(
  mergeMap(file => uploadFile(file))
).subscribe();

// concatMap - sequential
ids$.pipe(
  concatMap(id => deleteUser(id))
  // Wait for previous to finish before next
).subscribe();

// Updates when ANY source changes
this.filteredCourses$ = combineLatest([
  this.courseService.getAll(),
  this.searchTerm$,
  this.categoryFilter$,
  this.sortOrder$

      sort === 'asc'
        ? a.title.localeCompare(b.title)
        : b.title.localeCompare(a.title));
  })
);

ADVANCED ERROR HANDLING

Service-level error handling:

@Injectable({ providedIn: 'root' })
export class UserService {

  getAll(): Observable<User[]> {
    return this.http.get<User[]>(this.apiUrl)
      .pipe(
        retry({ count: 3, delay: 1000 }),
        timeout(5000),
        catchError(this.handleError)
      );
  }

  private handleError(
      error: HttpErrorResponse) {
    let message = '';
    if (error.status === 0) {
      message = 'Network error - check connection';
    } else if (error.status === 401) {
      message = 'Unauthorized - please login';
    } else if (error.status === 404) {
      message = 'Resource not found';
    } else if (error.status >= 500) {
      message = 'Server error - try again later';
    } else {
      message = error.error?.message ||
        'Unknown error';
    }
    return throwError(() => new Error(message));
  }
}

Global error handler:

@Injectable()
export class GlobalErrorHandler
    implements ErrorHandler {

  constructor(
    private notification: NotificationService,
    private logger: LoggerService) {}

  handleError(error: any): void {
    // Log error to backend
    this.logger.error(error);

    // Show user-friendly message
    const message = error.message ||
      'An error occurred';
    this.notification.error(message);

    // Re-throw for dev tools
    console.error(error);
  }
}

// Register
providers: [
  { provide: ErrorHandler,
    useClass: GlobalErrorHandler }
]

export const errorInterceptor:
    HttpInterceptorFn = (req, next) => {
  const router = inject(Router);
  const auth = inject(AuthService);

  return next(req).pipe(
    catchError((err: HttpErrorResponse) => {
      if (err.status === 401) {
        auth.logout();
        router.navigate(['/login']);
      } else if (err.status === 403) {
        router.navigate(['/forbidden']);
      } else if (err.status >= 500) {
        router.navigate(['/error']);
      }
      return throwError(() => err);
    })
  );
};

FILE UPLOAD — WITH PROGRESS

Upload Service:

@Injectable({ providedIn: 'root' })
export class FileService {
  private apiUrl = '/api/files';

  constructor(private http: HttpClient) {}

  uploadFile(file: File):
      Observable<HttpEvent<any>> {
    const formData = new FormData();
    formData.append('file', file, file.name);
    formData.append('description', 'My file');

    const req = new HttpRequest(
      'POST', this.apiUrl, formData, {
        reportProgress: true,
        responseType: 'json'
      });

    return this.http.request(req);
  }
}

Component with progress bar:

@Component({
  template: `
    <input type="file"
      (change)="onFileSelect($event)">
    <progress
      [value]="progress"
      max="100">{{ progress }}%
    </progress>
  `
})
export class UploadComponent {
  progress = 0;

  onFileSelect(event: any) {
    const file = event.target.files[0];
    if (!file) return;

    this.fileService.uploadFile(file)
      .subscribe((event: HttpEvent<any>) => {
        if (event.type ===
            HttpEventType.UploadProgress) {
          this.progress = Math.round(
            100 * event.loaded /
            (event.total || 1));
        } else if (event instanceof
            HttpResponse) {
          console.log('Upload complete!',
            event.body);
        }
      });
  }
}

@Component({
  template: `
    @for (course of courses; track course.id) {
      <app-course-card [course]="course"/>
    }
    <div #anchor></div>
  `
})
export class InfiniteScrollComponent
    implements OnInit, OnDestroy {

  @ViewChild('anchor', { static: true })
  anchor!: ElementRef;

  observer!: IntersectionObserver;

  ngOnInit() {
    this.observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          this.loadMore();
        }
      });
    this.observer.observe(this.anchor.nativeElement);

  loadMore() {
    this.courseService.getPage(this.page++)
      .subscribe(data =>
        this.courses.push(...data.content));
  }

  ngOnDestroy() { this.observer.disconnect(); }
}

HTTP CACHING IN ANGULAR

shareReplay — Cache Observable:

@Injectable({ providedIn: 'root' })
export class CategoryService {
  private categories$?: Observable<Category[]>;

  getAll(): Observable<Category[]> {
    if (!this.categories$) {
      this.categories$ = this.http
        .get<Category[]>('/api/categories')
        .pipe(
          shareReplay(1)  // Cache 1 emission
        );
    }
    return this.categories$;
  }

  // Force refresh

    this.categories$ = undefined;
  }
}

Custom Cache Service:

@Injectable({ providedIn: 'root' })
export class CacheService {
  private cache = new Map<string, {
    data: any,
    timestamp: number
  }>();

  get<T>(key: string): T | null {
    const item = this.cache.get(key);
    if (!item) return null;

    // Expire after 5 minutes
    if (Date.now() - item.timestamp > 300000) {
      this.cache.delete(key);
      return null;
    }
    return item.data;
  }

  set(key: string, data: any) {
    this.cache.set(key, {
      data,
      timestamp: Date.now()
    });
  }

  clear() {
    this.cache.clear();
  }
}

Pattern 1: takeUntil + Subject

export class UserListComponent

  private destroy$ = new Subject<void>();

CORS — CONNECTING ANGULAR & SPRING BOOT

CORS = Cross-Origin Resource Sharing. Browsers block requests from different origins by default.

The problem:

Angular runs on localhost:4200 calling Spring Boot on localhost:8080 → CORS error.

Solution 1: Configure Spring Boot

@Configuration
public class CorsConfig
    implements WebMvcConfigurer {
  @Override
  public void addCorsMappings(
      CorsRegistry registry) {
    registry.addMapping("/api/**")
      .allowedOrigins(
        "http://localhost:4200")
      .allowedMethods("*")
      .allowedHeaders("*")
      .allowCredentials(true);
  }
}

Solution 2: Angular Proxy (dev only)

// proxy.conf.json
{
  "/api": {
    "target": "http://localhost:8080",
    "secure": false,
    "changeOrigin": true,
    "logLevel": "debug"
  }
}

// angular.json
"serve": {
  "options": {
    "proxyConfig": "proxy.conf.json"
  }
}

// Or command line
ng serve --proxy-config proxy.conf.json

// In code, call /api/users
// instead of http://localhost:8080/api/users
this.http.get('/api/users');

Production: use nginx reverse proxy → same origin → no CORS.

LOADING & ERROR UI STATES

Pattern with BehaviorSubject:

interface State<T> {
  data: T | null;
  loading: boolean;
  error: string | null;
}

export class UserListComponent {
  state$ = new BehaviorSubject<State<User[]>>({
    data: null,
    loading: false,
    error: null
  });

  loadUsers() {
    this.state$.next({
      data: null,
      loading: true,
      error: null
    });

    this.userService.getAll().subscribe({
      next: (users) =>
        this.state$.next({
          data: users,
          loading: false,
          error: null
        }),
      error: (err) =>
        this.state$.next({
          data: null,
          loading: false,
          error: err.message
        })
    });
  }
}

Template:

@if (state$ | async; as state) {

  @if (state.loading) {
    <app-loading-spinner />
  }

  @if (state.error) {
    <app-error
      [message]="state.error"
      (retry)="loadUsers()" />
  }

  @if (state.data; as users) {
    @if (users.length === 0) {
      <p>No users found</p>
    } @else {
      @for (u of users; track u.id) {

@Injectable({ providedIn: 'root' })

    new BehaviorSubject<User | null>(
      this.getUserFromStorage());

      `${this.apiUrl}/login`,
      { email, password }
    ).pipe(
      tap((response) => {
        localStorage.setItem(
          'token', response.token);
        localStorage.setItem(
          'user', JSON.stringify(response.user));
        this.currentUser$.next(response.user);
      })
    );
  }

  logout() {
    localStorage.removeItem('token');
    localStorage.removeItem('user');
    this.currentUser$.next(null);
  }
}

  success: boolean;
  data: T;
  message?: string;
  errors?: { [key: string]: string };
}

@Injectable({ providedIn: 'root' })
export class UserService {

  getById(id: number): Observable<User> {
    return this.http.get<ApiResponse<User>>(
      `/api/users/${id}`
    ).pipe(
      map(response => {
        if (!response.success) {
          throw new Error(response.message);
        }
        return response.data;
      })
    );
  }
}

export const responseInterceptor:
    HttpInterceptorFn = (req, next) => {
  return next(req).pipe(
    map(event => {
      if (event instanceof HttpResponse &&
          event.body?.success) {
        return event.clone({
          body: event.body.data
        });
      }
      return event;
    })
  );

OPTIMISTIC UI UPDATES

Optimistic UI: Update the UI immediately (assuming success), rollback if API fails. → UX feels much faster.

Pessimistic (traditional):

deleteUser(id: number) {
  this.loading = true;
  this.userService.delete(id).subscribe({
    next: () => {
      this.users = this.users
        .filter(u => u.id !== id);
      this.loading = false;
    },
    error: () => {
      this.loading = false;
      alert('Failed');
    }
  });
}
// User must wait for response to see update

Optimistic:

deleteUser(id: number) {
  // Save current state for rollback
  const previousUsers = [...this.users];

  // Update UI IMMEDIATELY
  this.users = this.users
    .filter(u => u.id !== id);

  // Call API in background
  this.userService.delete(id).subscribe({
    next: () => {
      // Success - nothing more to do
      console.log('Deleted on server');
    },
    error: () => {
      // Rollback on failure
      this.users = previousUsers;
      this.notification.error(
        'Failed to delete - reverted');
    }
  });
}

When to use:

  • ✅ Like, favorite, bookmark
  • ✅ Delete with undo
  • ✅ Toggle status
  • ❌ Critical operations (payment)
  • ❌ Operations needing server validation

@Injectable({ providedIn: 'root' })
export class EventService {

  getServerEvents(): Observable<any> {
    return new Observable(observer => {
      const eventSource = new EventSource(
        '/api/events');

        observer.next(JSON.parse(event.data));
      };

      eventSource.onerror = (error) => {
        observer.error(error);
      };

      // Cleanup on unsubscribe
      return () => eventSource.close();
    });
  }
